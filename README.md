SaaS Pricing Card UI

A modern and responsive SaaS pricing card component built with a dark theme and vibrant purple accents.

✨ Features

- Monthly / Yearly billing toggle
- Three pricing plans: Basic, Pro, and Enterprise
- "Most Popular" highlighted plan
- Interactive hover effects
- Responsive design for desktop, tablet, and mobile
- Modern dark SaaS UI
- Smooth transitions and animations

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🎨 Color Palette

- Background: "#080B12"

🚀 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Or use the Live Server extension in VS Code.

📱 Responsive Design

The pricing cards automatically adapt to different screen sizes, providing a clean experience on desktop, tablet, and mobile devices.

🎯 Purpose

This project was created to practice responsive UI design, CSS hover effects, JavaScript interactions, and building a modern SaaS-style pricing component.
